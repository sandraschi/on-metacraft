# Glossary

**Revision date:** 2026-10-13.

- **Attachment point** - a place where a named party can still apply a
  brake, with the date it last held (series term; Ch VI).
- **Agent-hour** - one hour of wall-clock work by one model agent working
  sequentially; PhotoCraft's unit for remaining effort (Ch I, IV).
- **Checking cost** - the cost of verifying that a clone behaves like
  the original; sets the order in which software falls (Review D, Ch VIII).
- **Clean room** - reimplementation in which the people (or contexts) who
  study the original are separated from those who write the code by a
  vetted specification; an evidentiary practice, not a legal requirement
  (Ch III).
- **Craft / Crafting App** - one of the ArtCraft applications published by
  the `storytold` organization from 2026-09-30.
- **Foundry** - the reusable method that produces Crafts: spec, ground
  truth, budget, checkers, standards, release pipeline (Ch IX).
- **L0-L4** - proposed autonomy levels of a software foundry (Ch IX).
- **MetaCraft** - the foundry treated as an object of its own: the craft
  that makes crafts under agent control.
- **Oracle** - anything that can say cheaply and without a human whether
  an output is right: a reference implementation, a file corpus, a
  physical sample (Ch IV).
- **Parity floor** - the measured count of incumbent features present in a
  clone, which may only rise (Ch IV).
- **Switching cost** - the time a trained user loses moving to a program
  that works differently; the moat the clones attack (Ch III).
- **`[construction]`** - asserted, not yet evidenced. Required flag.
