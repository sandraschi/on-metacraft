# PRD - on-metacraft

**Status:** construction v0.1 (2026-10-13). Private repo. Audience: principals
who buy, sell, insure or regulate professional software.
**Series position:** fourth "On" book. on-ai-takeover sees SaaS collapse from
the buyer's ledger; this book sees it from the reimplementer's bench.

## Problem

Discourse on AI-written software sorts by capability ("can it write an app?")
or by panic ("it steals code"). Neither can be dated or acted on. Operators
need ordering by **which moat failed when**, each step an observable public
fact, each remaining moat named with who holds it.

See README. Short form: the moat was labor, not law.
